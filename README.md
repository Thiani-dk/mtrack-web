# M-Track: Civic Financial Intelligence Platform

## Mission
Disrupt predatory lending in Kenya by building a Civic Credit Score system that protects users from tax misuse through Income Defense logic.

## Core Features
- **Income Defense Technology**: Identifies non-taxable financial flows (remittances, loans, reimbursements) to protect users' PIN With No Obligation status
- **Repository Intelligence**: WhatsApp-integrated loan recovery system with snooze/schedule capabilities
- **Tax Butler**: Real-time expense categorization with eTIMS-ready compliance outputs
- **Document Intelligence**: AI-powered analysis of bank statements using Gemma 3.5

## Technical Stack
- **AI Engine**: Gemma 3.5 (local), Gemini 3 Flash, Claude 3.5 (audit)
- **Authentication**: Meta Cloud API (WhatsApp), KES 1 STK Push verification
- **Database**: PostgreSQL with Business_Accounts linking ShortCodes/MSISDNs
- **Deployment**: DigitalOcean Droplet (~KES 1,500/mo)

## Roadmap
1. **PDF Intelligence** (Days 1-4): Parse M-Pesa statements for financial activity classification
2. **WhatsApp Interface** (Days 5-7): Automated onboarding with Meta Cloud API integration
3. **Compliance Outputs** (Days 8-10): Generate reports for lenders and tax authorities
4. **Regulatory Filings** (Days 11-13): Prepare ODPC and National Treasury documentation

## Security Foundations
- Cryptographic identity verification
- Immutable transaction ledger
- "Unlocked and Shredded" data policy
